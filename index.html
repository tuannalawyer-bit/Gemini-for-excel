Gemini for Excel

Trợ lý AI thế hệ mới tích hợp trực tiếp vào Microsoft Excel. Tự do phân tích bảng tính, tự động viết công thức và chạy hàm AI ngay trong ô tính.

📥 Tải tệp Manifest.xml

🚀 Hướng Dẫn Cài Đặt Trong 1 Phút

1

Tải Manifest

Bấm nút "Tải tệp Manifest.xml" ở trên để lưu file cấu hình Add-in về máy tính của bạn.

2

Nạp vào Excel

Mở Excel > Thẻ Insert (Chèn) > Get Add-ins > Manage My Add-ins > Upload My Add-in > Chọn file manifest.xml vừa tải.

3

Dán API Key & Dùng

Mở Sidebar Gemini Assistant trên thanh Home > Vào thẻ Cài đặt > Dán API Key cá nhân của bạn từ Google AI Studio.

📐 Các Hàm Công Thức Hỗ Trợ

Cú pháp hàm Chức năng Ví dụ
=GEMINI.ASK(prompt, [context]) Hỏi đáp, phân tích, tóm tắt dữ liệu =GEMINI.ASK("Đánh giá tiềm năng khách hàng", B2)
=GEMINI.TRANSLATE(text, targetLang) Dịch văn bản sang ngôn ngữ bất kỳ =GEMINI.TRANSLATE(A2, "tiếng Anh")
=GEMINI.EXTRACT(text, whatToExtract) Trích xuất Email, SĐT, Ngày, Tên... =GEMINI.EXTRACT(A2, "số điện thoại")
=GEMINI.FORMULA(request, [sample]) Tự động sinh công thức Excel chuẩn =GEMINI.FORMULA("Tính tổng cột B nếu cột C ghi OK", A2:C10)
